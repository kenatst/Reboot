# REBOOT — Content evidence & scientific positioning

REBOOT is a behavioral training product. It does not diagnose, treat, or
make medical claims. "90 days" is the duration of the program, not a
biological reset guarantee.

## Product concepts and their evidence posture

- **Habit formation**: repeated, context-stable practice shapes automatic
  behavior. Claims are conservative; no universal "21/66/90 day" reset claim.
- **Implementation intentions**: if-then plans improve follow-through in
  reviewed literature; REBOOT uses them via environment contracts without
  citing effect sizes.
- **Attention residue**: switching leaves partial engagement with the
  previous task; REBOOT uses this concept descriptively, never as precise
  minutes.
- **Retrieval practice / reconstruction**: reconstructing from memory
  strengthens retention in educational psychology research; the app uses
  reconstruction and teach-back as training methods without fabricated stats.
- **Challenge–skill balance**: engagement conditions improve when perceived
  challenge matches skill; REBOOT treats this as a condition model, not a
  flow guarantee.
- **Flow**: REBOOT builds conditions (clear goal, feedback, challenge,
  distraction control) and explicitly never promises that flow occurs.
- **Sleep and attention**: sleep deprivation degrades attention; REBOOT
  adapts load on low-energy reports and never prescribes sleep protocols.
- **Caffeine and sleep**: effects vary by person; REBOOT only supports
  self-observation (association, not prescription).
- **Digital interruptions**: notifications and visual salience attract
  attention; wording avoids quantified "fragments memory for X minutes".
- **Environment design**: visible cues invite behavior; the intervention
  ladder uses this without claiming guaranteed effects.

## Sourcing policy

No fabricated citations. Where web research was unavailable, claims were
kept conservative and generic (descriptive mechanisms, not effect sizes).
Educational modules avoid absolute language and fake statistics.
