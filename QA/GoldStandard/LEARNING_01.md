# GOLD STANDARD — MODULE 01

**Titre** : LA MÉMOIRE DE TRAVAIL : LE MODÈLE DE BADDELEY
**Sujet** : Psychologie cognitive — modèle multicomposant

## Critères

- **SUJET SPÉCIFIQUE ?** OUI — le module enseigne le modèle de Baddeley, pas un prétexte à parler de téléphone.
- **RÉPÉTITIF ?** NON.
- **FACTUELLEMENT PLAUSIBLE ?** OUI — présente le modèle comme modèle théorique, évite l'anatomie, nuance les capacités.
- **ACTIONNABLE ?** OUI — l'application propose des stratégies d'allègement de la charge.
- **SONNE IA ?** BAS.
- **UN PAYANT LIrait-il ?** OUI — contenu de fond avec contre-exemple explicite.

## Contenu

**Hook** : Vous pouvez retenir un numéro de téléphone quelques secondes, mais pas un paragraphe entier : c'est la mémoire de travail en action.

**Idée centrale** : La mémoire de travail est un système de maintien et de manipulation de l'information, décrit par Baddeley comme un ensemble de composants coordonnés par un contrôleur attentionnel.

**Sections** : les composants (administrateur central, boucle phonologique, calepin visuospatial, buffer épisodique) ; le modèle est théorique, pas anatomique ; la saturation fait chuter la performance.

**Contre-exemple** : croire que la mémoire de travail est un « emplacement » dans le cerveau.

**Idée fausse** : « Le modèle de Baddeley décrit le cortex préfrontal. » Non : il décrit des fonctions.

**Application** : quand une tâche est saturée, écrivez les éléments, découpez-la et supprimez les interruptions.
